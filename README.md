# Thymian

A transparent clock and weather home screen widget for Android, styled after
the HyperOS Weather and Clock widget before a system update took its
transparency away. Sideloaded for one user, never published, non commercial.

**Status:** in development. The widget currently shows a transparent
placeholder.

```bash
./gradlew check assembleDebug
```
